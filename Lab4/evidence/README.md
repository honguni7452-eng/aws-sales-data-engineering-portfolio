# Lab4 검증 근거

공개 저장소에는 AWS 계정·역할·버킷·요청 식별 정보가 포함된 원본 화면과 전체 로그를 올리지 않습니다. 아래는 코드와 Athena 대조에서 확인한 공개 가능한 검증 항목입니다.

| 검증 대상 | 확인 내용 | 결과 |
| --- | --- | --- |
| Silver 주문 키 | 전체 주문 ID와 고유 주문 ID 비교 | 고유 비율 100% |
| Silver 날짜 파생 | 날짜·연도·월·주차의 NULL과 계산 결과 비교 | 불일치 0건 |
| Product Gold | Silver와 주문 수·매출 합계 비교 | 일치 |
| Daily Gold | 전 날짜의 누락·추가 행, 주문 수·매출 비교 | 불일치 0건 |
| 재실행 | 같은 입력으로 Glue Job 재실행 | 결과 유지 |

권한 오류 화면: [lab4_iceberg_permission_error.png](lab4_iceberg_permission_error.png) (식별 정보 가림)
